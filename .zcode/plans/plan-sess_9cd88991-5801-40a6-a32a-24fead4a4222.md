# tetrazero.com v2 — sriramph-style monochrome design with marcomadonna isometric 3D

## Context

The current site (Astro 6 + Tailwind 4 + GSAP, single page: Hero → Stats → About → Projects → Experience → Skills → Contact) uses an acid-green industrial look that reads as templated. The user wants a new version styled after **sriramph.com** (pure black/white monochrome, glass pills, floating dock, ghost typography, glow accents) with **marcomadonnadesign.com's signature isometric 3D modules** (hand-rolled SVG isometric engine with slow explode/assemble loops and hover-hold) spread across sections. Answers locked: monochrome "mostly black and white", dark-only, iso modules everywhere, no intro loader, no token playground, one small 3D module per featured project.

Work happens on a new branch `redesign/mono-iso` in the primary checkout; merge to master only after the user approves. No deploy in this work (user runs `/deploy` separately).

**Legal note:** marcomadonna's `iso.js` is unlicensed — we **reimplement the technique** (projection math, phase-clock architecture) in fresh code with our own module shapes, not a copy-paste.

## 2. Design foundation (US-001)

Rewrite `src/styles/global.css` tokens — monochrome ramp driven by lightness only:
- `#000` bg, surfaces `#0e0e10`/`#161618`, ink `#f5f5f5`, muted `#9a9a9a`, hairlines `rgba(255,255,255,.1)`, glass pill = `rgba(28,28,28,.6)` + `backdrop-blur(10px)`, white glow `rgba(255,255,255,.07–.28)` layered shadows
- Iso token pair mirroring mm's mono preset: `--iso-base: hsl(0 0% 34%)`, `--iso-edge: hsl(0 0% 80% / .5)`, accent faces = white at higher opacity
- Fonts: **Inter Variable** (display + body, sriramph-like neutral grotesque) + keep **JetBrains Mono**; swap the Google Fonts link in `Base.astro`; drop Syne/Bricolage; **drop AcidText** (replaced by scramble + glow motifs)

## 3. Isometric engine (US-002) — the core new piece

New vanilla TS module `src/scripts/iso/` (~300 lines, no deps):
- Box data tables `[x,y,z,w,d,h,layer,accent]`; projection `[(x−y)·cos30·S, ((x+y)/2−z)·S]`; yaw sway `0.3·sin(phase·2π)`; backface culling; directional light `lit = .32 + .62·max(0,n·L)`; painter sort by z-extents
- `PhaseClock`: 11s loop, layers close top-down (phase .08–.44) / reopen bottom-up (.56–.92), GAP .55; hover = Hermite seek to next integer phase with zero terminal velocity; leave = velocity decays to loop speed; staggered phases `i·.37` per module
- Assemble-on-scroll (IntersectionObserver ≥35%, 1.4s drop-in from +3.2z), shared rAF that fully stops when idle, polygon-node reuse via face-signature, precomputed fixed viewBox, `prefers-reduced-motion` static frame, touch pointers excluded from hover
- Custom module shapes for our content (hero mark, 3 tracks, 3 projects) defined as data
- Mount as a plain `<script>` in `Base.astro` scanning `[data-iso][data-module]` (no framework island needed)
