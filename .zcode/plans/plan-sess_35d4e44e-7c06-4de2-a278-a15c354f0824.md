Switch the GitHub profile SVG palette from acid-green-on-black to graphite + copper, in `generate_stats.py` (repo `WiredMind2/WiredMind2`, branch `main`). Scope: GitHub profile only — tetrazero.com keeps its current palette (intentional divergence, per user choice).

## Context

The current profile look — near-black `#08090b` + neon lime `#c8f750` — is the textbook "generated design" tell (the frontend-design skill literally lists "near-black background with a single bright acid-green accent" as a default nobody chooses on purpose). The user wants something that reads deliberate. Chosen direction: **graphite + copper** — warm graphite darks with a machined-copper accent (lathe dials / brass instruments / PCB copper feel), quiet rather than glowing. Layout and typography untouched.

## Changes — all in `generate_stats.py`

The palette is centralized, so this is a handful of hex swaps:

1. **`SHARED_STYLE` `:root` tokens** (drive every SVG via CSS vars):
   - `--night #08090b → #191817`, `--surface #0e1014 → #1f1e1c`, `--raised #14171c → #262421`
   - `--ink #e8e6e1 → #e9e6e0`, `--muted #8b919c → #8f8b84`, `--line #20242b → #2b2926`
   - `--acid #c8f750 → #c8864e`, `--acid-dim #8fb52e → #8f6136` (names kept — self-contained file, minimal diff; add a comment that the accent is now copper)
2. **`CONTRIB_COLORS` heatmap ramp** (levels 1–4): `#3d4a1e/#6f8c2c/#a3cf3d/#c8f750` → `#33291f/#5c4530/#8f6136/#c8864e` (level 0 stays `var(--raised)`).
3. **Stray hardcoded hexes**: language-color fallback in `build_stats_svg` (`#8b919c → #8f8b84`), repo-card `lang_color` fallback in `build_repo_card_svg` (`#c8f750 → #c8864e`).

Contrast sanity (pre-computed): copper on graphite ≈ 5.9:1, muted ≈ 5:1 — both pass for the small mono accent text used.

3. Grep all regenerated assets (`*.svg`): zero occurrences of the old hexes (`c8f750`, `8fb52e`, `08090b`, `3d4a1e`…); new tokens present.
4. Serve a page stacking every regenerated SVG (header, about, stats, featured heading, one card, footer buttons) on localhost, screenshot after animation settle (~3.5s), and run a visual pass: copper accent everywhere lime was, cohesive warm-dark neutrals, heatmap ramp reads as intensity, no unreadable text or leftover green.
