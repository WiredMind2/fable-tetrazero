### US-012: Isometric modules read as recognizable objects
**As a** visitor, **I want** each isometric module to visually resemble the thing it stands for (pipeline, chart, podium, …) **so that** the 3D marks reinforce each section's content instead of reading as random blocks.
**Points:** 5
**Status:** In progress
**Acceptance criteria:**
- [ ] Given the hero module at rest, when rendered, then its silhouette reads as a chunky "T" monogram
- [ ] Given each themed module (pipeline, chart, agents, board, shelf, podium, stack), when rendered at card size, then a first-time viewer can name what it depicts without being told
- [ ] Given `npm run build` after the change, when it completes, then it exits zero
- [ ] Given `prefers-reduced-motion: reduce`, when the page loads, then the new shapes render as static assembled frames
- [ ] Given a code review of the change, when the engine API (`Box` tuple, `MODULES` keys) is checked, then all component `data-module` references still resolve
