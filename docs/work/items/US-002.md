### US-002: Isometric 3D engine
**As a** visitor, **I want** animated isometric 3D modules (exploding layers, gentle sway, hover-to-rest) rendered as lightweight SVG **so that** the site has a signature animated identity without WebGL weight.
**Points:** 8
**Status:** Done
**Acceptance criteria:**
- [x] Given a `[data-iso][data-module]` element on any page, when the module scrolls ≥35% into view, then its boxes assemble over ~1.4s and the slow 11s explode/collapse loop starts
- [x] Given a module, when a non-touch pointer hovers its zone, then the loop accelerates to the next resting phase and parks there (no jump cuts); on leave the slow loop resumes
- [x] Given `prefers-reduced-motion: reduce`, when the page loads, then modules render one static assembled frame and no animation loop runs
- [x] Given two or more modules on screen, when both animate, then a single shared requestAnimationFrame drives both and it stops entirely when all modules are at rest or off-screen
