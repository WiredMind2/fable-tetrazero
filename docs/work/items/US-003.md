### US-003: Navigation with top social pill and bottom dock
**As a** visitor, **I want** a floating glass pill of contact links at the top and a floating section dock at the bottom **so that** navigation is always available without a traditional header.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given the desktop layout, when any section is viewed, then a glass pill top-right shows GitHub / LinkedIn / Email / Resume links and a centered glass dock at the bottom shows About / Work / Experience / Skills / Contact with the in-view section highlighted
- [x] Given scrolling between sections, when the active section changes, then the dock highlight moves to it (scroll-spy)
- [x] Given a 390px viewport, when the nav renders, then links collapse behind a hamburger that opens a sheet, and the bottom dock remains usable
