### US-001: Monochrome design tokens and font foundation
**As a** visitor, **I want** the site to use a pure black-and-white monochrome palette with a neutral grotesque typeface **so that** the portfolio reads as a deliberate, editorial product rather than a templated theme.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given any page, when rendered, then the palette is monochrome: black `#000` background, white/gray text ramp, `rgba(255,255,255,*)` hairlines and glows — no acid-green (`#c8f750`) token remains in `global.css` or component classes
- [x] Given the base layout, when fonts load, then Inter Variable (display + body) and JetBrains Mono (labels) are served via Google Fonts and Syne/Bricolage references are removed
- [x] Given any interactive surface, when styled, then glass pills use `rgba(28,28,28,.6)` + `backdrop-blur(10px)` and cards use the dark surface ramp (`#0e0e10`/`#161618`)
