### US-009: Motion polish — scramble headings, card-lift, custom cursor
**As a** visitor, **I want** consistent micro-motion (scrambling section headings, lifting cards, a custom cursor that reacts to interactive zones) **so that** the site feels alive and deliberate on every interaction.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given section headings marked for scramble, when they enter the viewport, then each resolves from scrambled characters once (no repeat on scroll-up)
- [x] Given interactive cards/links, when hovered, then they show the card-lift shadow transition and the custom cursor enters highlight mode over nav zones, links, and iso modules
- [x] Given `prefers-reduced-motion: reduce` or touch input, when the page loads, then the custom cursor is disabled and native cursors apply
